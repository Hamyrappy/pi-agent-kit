# Pi Agent Kit

A generic, shareable Telegram bridge for Pi. Keep all examples anonymous.
Never commit tokens, OAuth data, config.json, the user's vault, or session state.
Use Node >=22.19 and built-in APIs; pin Pi and commit package-lock.json.
Run npm test and npm run doctor after relevant changes. Tests must use fake
Telegram/Pi endpoints and temporary directories, without contacting real users.
Faces live in Markdown; shared memory belongs in the configured vault.
Do not modify a user's existing notes unless explicitly requested.

Use English for documentation, comments, docstrings, identifiers and default application text. Preserve intentional multilingual test fixtures and the user’s preferred conversation language. Product identity is independent of any installed Telegram bot’s name.
